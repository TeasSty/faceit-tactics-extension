Как работает панель прямо в комнате матча.

Автоматическое появление

Как только открываешь страницу faceit.com/.../cs2/room/<id>, расширение само определяет матч и подгружает данные — панель появляется справа поверх страницы.

Две вкладки

«Моя команда» — статистика и тактика твоих союзников. «Соперник» — статистика противников без тактических подсказок (это ведь их фишка, не твоя).

Сильные карты команды

Карта попадает в список, если минимум у одного игрока твоей команды winrate ≥ 55% при 5+ сыгранных матчах на ней.

Слабое звено соперника

Считается по произведению K/D и winrate — игрок с наименьшим значением помечается приоритетной целью для давления.

История личных встреч

Расширение просматривает последние ~30 матчей каждого игрока твоей команды и ищет пересечения с текущими соперниками, считая счёт побед и поражений.

Help

Частые вопросы.

Кнопка «Вставить тактику в чат» не находит поле чата

FACEIT периодически меняет вёрстку. В этом случае текст тактики копируется в буфер обмена автоматически — просто вставь его в чат сочетанием Ctrl+V.

Не вижу CT/T статистику по карте

Эти поля не всегда есть в публичном FACEIT Data API для конкретного игрока или карты — блок появляется только когда данные доступны.

Панель пишет, что сервер недоступен

Сервер-прокси расширения временно не отвечает. Обнови страницу матча через минуту; если не помогает — обратись к автору расширения.

В панели соперник показан под вкладкой «Моя команда»

Порядок команд в ответе FACEIT API не всегда совпадает со стороной зрителя — просто переключись на вторую вкладку.
