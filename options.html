FACEIT Tactics Assistant

Расширению нужен персональный API-ключ FACEIT Data API, чтобы читать статистику матча и игроков. Ключ хранится только в твоём браузере (chrome.storage.sync) и никуда не отправляется, кроме официального API FACEIT.

  1. Зайди на developers.faceit.com/apps и войди под своим FACEIT-аккаунтом.
  2. Создай приложение (Create new app), любое название.
  3. В разделе API keys создай ключ типа Server-side.
  4. Скопируй ключ и вставь его ниже.
