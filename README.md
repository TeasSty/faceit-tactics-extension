# FACEIT Tactics Assistant

Расширение для Chrome (Manifest V3), которое встраивается в страницу комнаты матча CS2 на faceit.com и показывает:

- статистику каждого игрока (K/D, winrate, HS%, ELO, уровень, кол-во матчей) под его карточкой;
- персональную тактическую подсказку для каждого игрока своей команды с кнопкой **«Вставить тактику в чат»** — текст подставляется в поле командного чата, отправляешь сам;
- сводку по команде: сильные карты (по статистике игроков) и слабое звено в составе соперника — приоритетная цель для давления.

Тестовая комната: https://www.faceit.com/ru/cs2/room/1-b6fc5076-c2c1-4bd3-9264-d56e9c315ed4 (после того как матч сыгран, панель всё равно подтянет статистику; для актуальной тактики открывай расширение в комнате матча, который вот-вот начнётся — тогда же известна выбранная карта).

## Установка (Chrome / Edge, режим разработчика)

1. `chrome://extensions` → включить **Режим разработчика** (переключатель справа вверху).
2. **Загрузить распакованное расширение** → выбрать папку `faceit-tactics-extension`.
3. Открыть настройки расширения (иконка → «Настройки / API-ключ») и вставить свой ключ FACEIT Data API.

## Получение API-ключа FACEIT

1. Зайти на https://developers.faceit.com/apps под своим FACEIT-аккаунтом.
2. Создать приложение (любое название).
3. В разделе API keys создать ключ типа **Server-side**.
4. Скопировать и вставить в настройках расширения. Ключ хранится только локально в браузере (`chrome.storage.sync`) и используется только для запросов к `open.faceit.com`.

## Как пользоваться

1. Открыть страницу комнаты матча CS2: `faceit.com/.../cs2/room/<id>`.
2. Справа появится панель с двумя вкладками — «Моя команда» и «Соперник».
3. Под каждым игроком своей команды — статистика и персональная тактика с кнопкой вставки в чат.
4. Панель сворачивается стрелкой в заголовке (состояние запоминается).

## Ограничения и техническая логика

- Данные берутся из официального FACEIT Data API (`open.faceit.com/data/v4`), а не парсингом DOM — это устойчивее к изменениям вёрстки сайта.
- Персональная тактика — это генерация по простым правилам на основе K/D, HS%, winrate по текущей карте (если карта уже выбрана в вето) и текущей серии побед/поражений. Это подсказка, а не готовый игровой план — адаптируй под конкретную ситуацию.
- Кнопка вставки в чат ищет поле ввода чата на странице по нескольким селекторам и просто подставляет туда текст (без авто-отправки) — отправляешь сообщение сам. Если поле чата не найдено (FACEIT изменил вёрстку), текст копируется в буфер обмена, и появляется уведомление — вставь вручную (Ctrl+V).
- Если расширение показывает состав соперника под вкладкой «Моя команда» и наоборот — это ограничение API (порядок факций не всегда совпадает со стороной зрителя); переключись на вторую вкладку.

## Структура проекта

```
manifest.json     — конфигурация расширения (MV3)
background.js     — service worker, запросы к FACEIT Data API с сохранённым ключом
content.js        — логика на странице комнаты: определение матча, рендер панели, тактики
content.css       — тёмная премиальная тема панели
options.html/js   — страница настроек (ввод API-ключа)
popup.html/js     — всплывающее окно иконки расширения
```
