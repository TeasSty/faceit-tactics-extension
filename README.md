# FACEIT Tactics Assistant

Расширение для Chrome (Manifest V3), которое встраивается в страницу комнаты матча CS2 на faceit.com и показывает:

- статистику каждого игрока (K/D, winrate, HS%, ELO, уровень, кол-во матчей, при наличии в API — winrate по стороне CT/T на текущей карте) под его карточкой;
- персональную тактическую подсказку для каждого игрока своей команды — свёрнута по умолчанию (раскрывается по клику, не мешает), с кнопкой **«Вставить тактику в чат»** — текст подставляется в поле командного чата, отправляешь сам; полностью отключается в настройках, если не нужна;
- сводку по команде: сильные карты (по статистике игроков), слабое звено в составе соперника и историю личных встреч (head-to-head) с игроками соперника из истории матчей.

Тестовая комната: https://www.faceit.com/ru/cs2/room/1-b6fc5076-c2c1-4bd3-9264-d56e9c315ed4 (после того как матч сыгран, панель всё равно подтянет статистику; для актуальной тактики открывай расширение в комнате матча, который вот-вот начнётся — тогда же известна выбранная карта).

## Архитектура: ключ FACEIT API только на сервере

Расширение **не хранит и не спрашивает** у пользователя API-ключ. Вместо
прямых запросов к `open.faceit.com` оно обращается к собственному
прокси-серверу (Cloudflare Worker, см. [`server/`](server)), который держит
ключ в секретах и сам ходит в FACEIT Data API. Пользователь после установки
сразу получает рабочее расширение — ничего вводить не нужно.

```
Расширение (Chrome)  →  Cloudflare Worker (secret: FACEIT_API_KEY)  →  open.faceit.com
```

Владельцу проекта нужно один раз задеплоить воркер и прописать его адрес в
[`config.js`](config.js) — подробная инструкция в
[`server/README.md`](server/README.md).

## Установка (Chrome / Edge, режим разработчика)

1. Задеплой сервер по инструкции в [`server/README.md`](server/README.md) и пропиши его адрес в `config.js` (нужно сделать один раз, до загрузки расширения — иначе расширение будет показывать «сервер недоступен»).
2. `chrome://extensions` → включить **Режим разработчика** (переключатель справа вверху).
3. **Загрузить распакованное расширение** → выбрать папку `faceit-tactics-extension`.
4. При первой установке автоматически откроется приборная панель расширения — можно сразу идти в комнату матча, настраивать нечего.

## Как пользоваться

1. Открыть страницу комнаты матча CS2: `faceit.com/.../cs2/room/<id>`.
2. Справа появится панель с двумя вкладками — «Моя команда» и «Соперник».
3. Под каждым игроком своей команды — статистика и персональная тактика (сворачиваемая) с кнопкой вставки в чат.
4. Панель сворачивается стрелкой в заголовке (состояние запоминается).

## Панель настроек

Открывается по клику на иконку расширения → «Открыть настройки», либо
автоматически один раз при первой установке. Разделы: Dashboard, Matchroom,
Player Stats, Maps, Settings (переключатели «показывать тактику» / «показывать
сводку по команде», статус подключения к серверу), Premium, Discord, Help,
About.

## Ограничения и техническая логика

- Данные берутся из официального FACEIT Data API (`open.faceit.com/data/v4`) через собственный прокси-сервер, а не парсингом DOM — это устойчивее к изменениям вёрстки сайта.
- Персональная тактика — это генерация по простым правилам на основе K/D, HS%, winrate по текущей карте (если карта уже выбрана в вето) и текущей серии побед/поражений. Это подсказка, а не готовый игровой план — адаптируй под конкретную ситуацию.
- Кнопка вставки в чат ищет поле ввода чата на странице по нескольким селекторам и просто подставляет туда текст (без авто-отправки) — отправляешь сообщение сам. Если поле чата не найдено (FACEIT изменил вёрстку), текст копируется в буфер обмена, и появляется уведомление — вставь вручную (Ctrl+V).
- Если расширение показывает состав соперника под вкладкой «Моя команда» и наоборот — это ограничение API (порядок факций не всегда совпадает со стороной зрителя); переключись на вторую вкладку.

## Структура проекта

```
manifest.json     — конфигурация расширения (MV3)
config.js         — адрес прокси-сервера (без секретов, публичный файл)
background.js     — service worker, запросы к прокси-серверу
content.js        — логика на странице комнаты: определение матча, рендер панели, тактики
content.css       — тёмная премиальная тема панели матча
options.html/css/js — приборная панель расширения (Dashboard/Settings/Help/…)
popup.html/js     — всплывающее окно иконки расширения
icons/            — иконки расширения (16/32/48/128px)
_locales/ru/      — строки name/description манифеста (нужно для default_locale)
server/           — Cloudflare Worker — прокси к FACEIT API, держит секретный ключ
```
