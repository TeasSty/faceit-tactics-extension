# FACEIT Tactics Assistant

Расширение для Chrome (Manifest V3). Никакой отдельной панели или окна —
статистика и тактика встраиваются прямо в разметку faceit.com, компактным
блоком под каждым игроком, в тёмной теме, только с фирменным акцентом
FACEIT (оранжевый) и тонкими разделителями вместо рамок.

- под каждым игроком в комнате матча — компактный блок статистики: K/D,
  winrate, HS%, ELO, уровень, число матчей, CT/T winrate по текущей карте
  (если API отдаёт), любимая и слабая карта, форма по последним матчам, а
  для своей команды — ещё и winrate по полной истории (~30 матчей); любые
  дополнительные поля, которые реально возвращает FACEIT API для конкретного
  игрока, показываются в раскрывающемся «Ещё статистика», а не выдумываются —
  если поля нет, блок просто не показывается;
- для своей команды — сворачиваемая тактика с кнопкой **«Вставить в чат»**
  (текст подставляется в поле чата только по клику, никогда не отправляется
  автоматически). Это не гайд по гранатам и не план на раунд — короткий
  совет по игровому стилю на основе своей статистики плюс приоритетная цель:
  самый слабый по статистике игрок соперника, чтобы команде было проще
  понять, на кого давить;
- после завершения матча — аналитика по итогам: K/D в этом матче против
  своего обычного среднего, лучший и худший игрок своей команды по этому
  матчу (в popup, не загромождает страницу);
- всё управление — через компактный popup иконки расширения (380×600):
  статус сервера, сводка по текущему матчу, переключатели функций,
  переключатель языка (RU/EN, при первой установке определяется языком
  браузера), версия, About, Changelog, Premium, «Сообщить о баге».

Тестовая комната: https://www.faceit.com/ru/cs2/room/1-b6fc5076-c2c1-4bd3-9264-d56e9c315ed4

## Архитектура: ключ FACEIT API только на сервере

Расширение **не хранит и не спрашивает** у пользователя API-ключ. Вместо
прямых запросов к `open.faceit.com` оно обращается к собственному
прокси-серверу (Cloudflare Worker, см. [`server/`](server)), который держит
ключ в секретах и сам ходит в FACEIT Data API. Пользователь после установки
сразу получает рабочее расширение — ничего вводить не нужно.

```
Расширение (Chrome)  →  Cloudflare Worker (secret: FACEIT_API_KEY)  →  open.faceit.com
```

Владельцу проекта нужно один раз задеплоить воркер и прописать его адрес в
[`config.js`](config.js) — подробная инструкция в
[`server/README.md`](server/README.md).

`EXTENSION_SHARED_KEY` в `config.js` — это не пароль от чего-то
существующего, а произвольная случайная строка, которую ты сам придумываешь
(например, `openssl rand -hex 20`) и прописываешь в двух местах: в
`config.js` и через `wrangler secret put EXTENSION_SHARED_KEY` на сервере —
она просто должна совпадать в обоих местах, воркер сверяет её как общий
пароль между расширением и собой.

## Установка (Chrome / Edge, режим разработчика)

1. Задеплой сервер по инструкции в [`server/README.md`](server/README.md) и пропиши его адрес и `EXTENSION_SHARED_KEY` в `config.js` (нужно сделать один раз, до загрузки расширения — иначе блоки статистики не появятся).
2. `chrome://extensions` → включить **Режим разработчика** (переключатель справа вверху).
3. **Загрузить распакованное расширение** → выбрать папку `faceit-tactics-extension`.
4. При первой установке откроется короткая страница приветствия (не панель настроек) — дальше настраивать нечего.
5. Иконка новых расширений в Chrome по умолчанию спрятана за значком пазла в панели инструментов — нажми на пазл и закрепи FACEIT Tactics Assistant булавкой, чтобы она была видна постоянно (это стандартное поведение Chrome, не баг расширения).

## Как пользоваться

1. Открыть страницу комнаты матча CS2: `faceit.com/.../cs2/room/<id>`.
2. Под каждым игроком (своим и соперником) прямо в разметке страницы появится компактный блок статистики.
3. Под своими игроками — ещё и сворачиваемая тактика с кнопкой вставки в чат.
4. После завершения матча — открой popup иконки расширения, там появится блок «Итоги матча».
5. Клик по иконке расширения — единственное место с настройками: язык, переключатели, About, Changelog, Premium, репорт бага.

## Ограничения и техническая логика

- Данные берутся из официального FACEIT Data API (`open.faceit.com/data/v4`) через собственный прокси-сервер, а не парсингом DOM — это устойчивее к изменениям вёрстки сайта для самих данных.
- Встраивание блоков в страницу, наоборот, завязано на DOM: FACEIT — SPA с обфусцированными CSS-классами, поэтому расширение ищет место для блока по точному совпадению текста никнейма игрока на странице, а не по стабильным селекторам. Это единственный практичный способ без доступа к исходному коду сайта, но он может давать сбой, если FACEIT изменит вёрстку или у двух элементов совпадёт текст — в этом случае блок для конкретного игрока просто не появится (без ошибок и без резервной большой панели, по дизайну).
- «Итоги матча» строятся на `/matches/{id}/stats`, который FACEIT отдаёт только когда матч уже завершён (`status: FINISHED`). Изменение ELO и уровня «до/после» показать нельзя: публичный API не отдаёт исторический дельта ELO, а без собственного сервера с базой данных, который бы заранее сохранял ELO каждого игрока, это не восстановить достоверно — поэтому такого блока сознательно нет, вместо выдуманных цифр.
- Кнопка вставки в чат ищет поле ввода чата на странице по нескольким селекторам и подставляет туда текст (без авто-отправки). Если поле не найдено, текст копируется в буфер обмена — вставь вручную (Ctrl+V).
- «Любимая/слабая карта» считается по сегментам статистики игрока (winrate по картам, минимум 3 матча на карте). CT/T winrate показывается, только если FACEIT API реально отдаёт такой сегмент для аккаунта игрока — часто его там нет, и тогда строка просто не рисуется.
- Порядок команд (своя/соперник) — эвристика по порядку в ответе API, не всегда совпадает со стороной зрителя.
- Локализация (RU/EN) — собственный словарь в `i18n.js`, переключается вручную в popup и не зависит от языка браузера после первого выбора. Сгенерированный текст тактики (не UI-строки) пока остаётся только на русском.

## Структура проекта

```
manifest.json     — конфигурация расширения (MV3)
config.js         — адрес прокси-сервера и общий секрет (без FACEIT-ключа)
i18n.js           — словарь RU/EN и определение языка
background.js     — service worker, запросы к прокси-серверу, приветствие при установке
content.js        — логика на странице комнаты: поиск матча, встраивание блоков статистики в DOM
content.css       — минималистичная тёмная тема встроенных блоков (только тонкие разделители)
welcome.html      — одноразовая страница приветствия при первой установке
popup.html/css/js — единственная поверхность настроек: статус, сводка, итоги матча, язык, About/Changelog/Premium/репорт
icons/            — иконки расширения (16/32/48/128px)
_locales/ru/      — строки name/description манифеста (нужно для default_locale)
server/           — Cloudflare Worker — прокси к FACEIT API, держит секретный ключ
```
